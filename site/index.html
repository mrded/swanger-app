Swanger

OpenAPI schema viewer for macOS

Open an OpenAPI 3.0 or 3.1 file (JSON or YAML) and see every request and response body as an interactive block diagram.

Download for macOS Source on GitHub

Free and open source (MIT). Needs macOS 15 Sequoia or later.

Schemas as diagrams

Every request and response body schema becomes a block diagram you can open up card by card. The inspector spells out each field's rules in plain English.

See what's shared

The overview has a card for each request and response schema, and a grid of the shared fragments (components/schemas) each one is built from.

Try it

Paste a JSON payload and Swanger checks it against the schema, explaining in plain English what's wrong.

Not an API explorer

Swanger shows schemas only. It has no endpoint list, parameters, servers or auth, and it never sends requests. It reads paths only to find which schemas are request and response bodies.

Installing

  1. Download Swanger-<version>.dmg from the latest release and drag Swanger.app into Applications.
  2. Apple hasn't notarised releases yet, so macOS blocks Swanger the first time you open it. Click Done, then open System Settings › Privacy & Security, scroll down to the message about Swanger and click Open Anyway. You only need to do this once.

Or remove the quarantine flag in Terminal instead:

xattr -dr com.apple.quarantine /Applications/Swanger.app
